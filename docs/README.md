# Documentación del proyecto

Esta carpeta contendrá documentación complementaria de ingeniería y operación, por ejemplo:

- Guías de instalación y ejecución local.
- Instrucciones de desarrollo y pruebas.
- Convenciones de contribución.
- Registros técnicos que no sustituyan las especificaciones aprobadas.

Las decisiones normativas y los contratos aprobados pertenecen a `specs/`.
