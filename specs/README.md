# Especificaciones aprobadas

Esta carpeta contendrá las versiones completas y aprobadas que constituyen la fuente de verdad funcional y técnica del proyecto.

Documentos aprobados al 14-11-2026:

- SPEC-001 a SPEC-006 — especificaciones funcionales y no funcionales.
- ARCH-001 v0.1 — arquitectura técnica.
- DATA-001 v0.2 — modelo de datos y estructura JSON.
- API-001 v0.1 — contratos de endpoints REST.
- UI-001 v0.1 — identidad visual e inventario de componentes.

Los documentos se incorporarán en archivos individuales, conservando su contenido, versión, decisiones y estado de aprobación. Este índice no sustituye los documentos originales.

No modificar una especificación aprobada sin una solicitud explícita y un cambio de versión trazable.
